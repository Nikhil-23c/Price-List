# Pricing Plans Landing Page

A responsive three-plan pricing section built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build tools or dependencies are required.

## Files
- `index.html` — page structure and plan data attributes
- `style.css` — responsive layout, card styling, hover transitions, ribbons
- `script.js` — Monthly/Yearly billing toggle

## Features
- Three fictional plans: Starter, Professional, Enterprise
- Monthly/Yearly switch with `data-monthly` and `data-yearly` HTML attributes
- Popular and Best Value ribbons
- CSS hover transforms and transitions
- Responsive layout for mobile and desktop
- Accessible real button elements and reduced-motion support

All prices are fictional demonstration prices.
